# Inspect the robustness case

Open the prebuilt robustness viewer from the repository guide, or run `python -B run.py demo --case robustness` from `observation-receipt` and open the printed viewer path. Python 3.11+ and no additional package, account or network connection are required.

Choose **Inspect the 48-field crossing**, then change the hypothetical budget to 47. For the fixed-nonblank combined-byte model, the majority is guaranteed at 47 hypothetical membership changes but not at 48. This does not identify actual erroneous tags, estimate an error rate or show a target-ranking reversal.

Switch to the full cohort at r = 0. The interval now includes unknown blanks. Use **Inspect source** on a witness row to recover its original action, activity, product IDs and CSV row locators. Completion priority is a different job from validating recorded tags. Equal-field-cost guarantees are not statistical sample sizes or real cost-optimal review queues.

If browser downloads fail, use the CSVs included beside the prebuilt viewer. The source package also includes the pinned receipt and source manifest. Altered source bytes block evaluation; a hash mismatch is not permission to silently repin.

Run `python -B -m unittest discover -s tests -v` from the application directory to check the portable consumer and failure paths. These checks attest byte/accounting behavior, not physical identities, content labels, human comprehension or scientific acceptance.
