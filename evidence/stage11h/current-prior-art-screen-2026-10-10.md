## Findings

The exact searches did not locate another public analysis reporting the Testbed's Sunset denominator chain, 4,290-product connected context, action/product/byte rank reversals, plan-realization boundary divergence, or camera-composition shift from protocol multiplicity. Search absence is not proof that none exists.

NASA's release page continues to frame the material as more than 800 GB, more than 11,000 full-resolution images and video, audio, notes, and annotations that form a dataset for exploration. It does not claim that files are IID samples, that one row unit is statistically neutral, or that the release is a prebuilt machine-learning benchmark.

The official PDS mission page explicitly tells users to read the Data User Guide for archive organization and processing and exposes the Targeting Package and Outgoing Target Request as separate documentation products. That supports the Testbed's layered source model; it does not supply the product→exposure→action→plan→realization graph constructed here.

The surfaced Hugging Face dataset is a separate 170-kB mission-summary resource with trajectory, timeline, crew, and payload tables. It does not package or analyze the crew-camera archive and is not prior art for the current denominator or weighting findings. Its existence is useful as a reminder that “Artemis II dataset” is an ambiguous public label.
