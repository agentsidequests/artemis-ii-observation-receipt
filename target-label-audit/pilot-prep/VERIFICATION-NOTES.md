# Metadata-only pilot preparation: verification scope

This is a private candidate-preparation receipt, not an executed image audit or an accepted scientific method. The owning protocol and exact runtime-generated identities are in the linked preparation files.

## What is checked

- Exact frozen manifest, archive-locator anchor and target-plan hashes before use.
- Distinct captures/actions, fixed per-phase tag-metadata quotas and camera/coverage-regime breadth.
- A deterministic, purposeful selection rule and input-order-invariant replay, not random inclusion probabilities.
- Three native representations per capture, source-field preservation and recomputed byte sums.
- Opaque calibration-only queue fields, with the original metadata and confirmation reserve in a separate steward file.
- Refusal of source-hash changes, infeasible quotas, product path traversal, false execution flags and overwriting differing existing artifacts.
- UTF-8/LF artifact generation and hashes; no model, pixels, downloader or annotation engine.

The tests check their named seams only. They do not detect arbitrary semantic overclaims, validate lunar content, prove secure blinding, certify unviewed images or establish general prevention. Two implementations recounting one metadata source are partially independent accounting checks, not independent scientific corroboration.

## Inspection faults and repair disposition

An initial read-only file search used wildcard strings as literal Windows paths; it was corrected with scoped file globs and an inventory. A metadata probe then picked a query JSON rather than a response JSON; it was corrected to the observed `batch-*-response.json` carrier. Neither fault changed source bytes or any external state. The preparation runner uses exact pinned inputs instead of either discovery route.

The first focused test run had one wording assertion mismatch: the packet said there was no ready-to-score image bundle, while the assertion expected different words. The asserted phrase was corrected to the existing boundary and the complete focused set was rerun. This was a test-text mismatch, not a scientific result or a failed blinding experiment.
