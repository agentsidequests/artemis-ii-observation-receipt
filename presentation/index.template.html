02 / Selection + weighting
A blank field has no vote.
That does not make it a negative.
Only 3,413 of 7,606 native target fields are nonblank. Filtering out the other 4,193 changes the population before an image model sees a pixel.

The first change is selection: the recorded Sunset fields remain 1,553, while the denominator falls from 7,606 to 3,413. The second is influence: inside the selected population, actions, exposures and attached bytes are different measures.
The combined-byte majority is not universal. Source-representation bytes start below half; raw and processed bytes start above it. Bytes measure an archive-accounting quantity, not scientific importance or physical prevalence.

05 / Detection
The observer changed.
The clock kept ticking.
Five accepted crew-reported events, eight witness marks and three observers are not one stationary hour of detection. Attention, glare, display brightness, adaptation, workflow and prompting changed.


Transcript anchor, not a numbered event assignment
The transcript supports changing observation conditions. It does not estimate detection probability, prove prompt causation, establish witness independence or physical flash clustering.



Nine hundred frames are not a sensitivity certificate.
A separate 15-second transcoded clip overlaps one clear report. Its threshold-defined lunar footprint is only 10 by 9 pixels. A no-pulse screen becomes informative only if it can recover the signal it is supposed to exclude.
Requested injection levels differ from realized additions after rounding and clipping. These are uncalibrated transcoded-video units, not astronomical brightness.
0.0%clip-native recovery
The null is non-exclusionary. Recovery never reached 50% in the tested grid. This does not confirm an impact in the clip, characterize the flight sensor or overturn NASA's accepted classifications.
1,458 deterministic synthetic trials, not 1,458 physical flashes. No calibrated human threshold, event photometry or lunar impact flux is available.
Inspect the synthetic recovery model and its ceiling
Normalized Gaussian additions in grayscale, rounded and clipped to uint8, then evaluated by the frozen local screen. Brightness-conditioned effective area-time requires a calibrated detection function, not raw frames or clock time.
